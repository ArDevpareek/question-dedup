How to put version 1 on GitHub
==============================

The GitHub CLI ("gh") was not installed, so nothing was pushed.
Run these commands in PowerShell, in the project folder:
    cd D:\Code\AI_Question_Generation\question-dedup

Option A - with the GitHub CLI (easiest)
----------------------------------------
1. Install it (once):
       winget install --id GitHub.cli
   Then close and reopen PowerShell.
2. Log in (once). It opens the browser:
       gh auth login
3. Create a PRIVATE repo from this folder and push main plus the tag:
       gh repo create question-dedup --private --source=. --remote=origin
       git push -u origin main --follow-tags
   If the name "question-dedup" is already taken in your account, use:
       gh repo create question-dedup-v1 --private --source=. --remote=origin
       git push -u origin main --follow-tags

Option B - without the GitHub CLI
---------------------------------
1. On github.com, create a new PRIVATE repository named question-dedup
   (or question-dedup-v1 if that name is taken). Do NOT add a README, .gitignore or licence.
2. Then run (replace YOUR-USERNAME):
       git remote add origin https://github.com/YOUR-USERNAME/question-dedup.git
       git push -u origin main --follow-tags

Check that it worked
--------------------
       git ls-remote --tags origin
   should list refs/tags/v1-two-gate.
